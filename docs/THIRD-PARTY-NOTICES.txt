How the programs fit together
-----------------------------
YTRadioMini.exe does not contain or link to mpv or yt-dlp. It starts mpv.exe and yt-dlp.exe as
separate processes and talks to them through a pipe and through command-line arguments. The
three are delivered together in one folder for convenience; they remain separate works, each
under its own licence. Licence texts are in the "licenses" folder (see licenses/README.md).

Exact versions and SHA-256 checksums of the bundled programs are in docs\DEPENDENCIES.txt of the
release package. In the package, mpv.exe and yt-dlp.exe are in the "tools" folder.

Source code for the GPL-licensed programs
-----------------------------------------
Where the licence of a bundled program requires it, the corresponding source code is available at
the addresses given above. If you received this package and cannot obtain the source code of mpv.exe
or yt-dlp.exe from those addresses, open an issue at
https://github.com/Schwarz-XU/yt-radio-mini/issues and ask for it. The source code will be provided
or its location pointed out.

If you do not want to receive mpv.exe and yt-dlp.exe from this package, you can delete them and put
your own copies of the programs (from https://mpv.io and https://github.com/yt-dlp/yt-dlp/releases)
in the "tools" folder, or in a folder on the PATH.
